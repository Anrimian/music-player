# Simple Music Player

A music player for Android that I wrote for myself, in accordance with my vision of how a music player should look like.

## Two versions

**Simple Music Player** is the main app. It plays music from your device, and can optionally sync your audio library with cloud storage.

<a href='https://play.google.com/store/apps/details?id=com.github.anrimian.musicplayer&pcampaignid=pcampaignidMKT-Other-global-all-co-prtnr-py-PartBadge-Mar2515-1'><img alt='Get it on Google Play' src='https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png' height=65px/></a>

**Simple Music Player Offline** is the same app without sync, and without the internet permission at all.

<a href='https://play.google.com/store/apps/details?id=com.github.anrimian.musicplayer.lite&pcampaignid=pcampaignidMKT-Other-global-all-co-prtnr-py-PartBadge-Mar2515-1'><img alt='Get it on Google Play' src='https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png' height=65px/></a>

Also built as a standalone app in [releases](https://github.com/Anrimian/music-player/releases).

## About the source code here

This repository contains the source of the Offline version. The sync modules are not published.

Issues and releases here cover both apps.

## Feedback

If something is broken, or you want to suggest something, write to smusicplayer.feedback@gmail.com or open an issue. If you go with issues, look through the existing ones first, and just leave a reaction if your case is already there.

## Translations

Translations are provided by users on [Crowdin](https://crowdin.com/project/s-music-player).

How to use it: sign up, open the project, pick your language, then open the file and type your version of each string. Translations are suggestions, so you can't break anything by trying. If you want to review and approve strings for your language, ask me for proofreader access.

If your language is missing from the list, write to me and I'll add it.
